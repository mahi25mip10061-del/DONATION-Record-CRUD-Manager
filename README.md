▷ PROJECT TITLE :-

  --DONATION RECORD CRUD MANAGER--
     
▷ OVERVIEW OF THE PROJECT :-
The Donation Records CRUD Manager is a console-driven Python application that helps maintain and organize donation details.
it is ideal for small NGOs, events, fundraisers, classrooms, or college clubs that need a basic digital donation register.

  This project focuses on:
    ▪ Building a logical workflow
    ▪ Understanding CRUD operations
    ▪ Designing modular functions
    ▪ Managing data in memory
    ▪ Applying programming fundamentals

▷ Key Features :-
 ▪ Add Donation (Create) :
    Allows entry of donor name, phone number, donation amount, and date.

▪ View All Donations (Read) :
    Displays all stored donations in a clean, formatted list.

▪ Update Donation (Update) :
    Users can modify donor details based on donor name.

▪ Delete Donation (Delete) :
    Removes a donor record from the system.

▪ Menu-Driven Interface :
    Simple and intuitive console interface suitable for beginners.

▷ TECHNOLOGIES/TOOL USED :-
   ▪ Python 
   ▪ Console-based user interface
   ▪ Data structures : Lists & Dictionaries

▷ STEPS TO INSTALL & RUN THE PROJECT
   1. Install Python
       Make sure python is installed on your computer.
        check by running this in your terminal:
           pyhton --version
      if python is not installed, download if from:
        https://www.python.org/downloads/

   2. Download the project
       Download or clone the project folder from GitHub.
         Option A - Download ZIP:
           1. Open the GitHub repository
           2. Click on Code button
           3. Select Download ZIP
           4. Extract the ZIP file
         Option B - Clone using Git
                      git clone

   3. Open the project folder
         Navigate to the project directory:
            cd Donation-records-CRUD-manager

   4. Run the Program
         Run the python script using:
            pyhton donation_manager.py

   5. Use the Application
         The Menu will appear:
            1. Add Donor Record
            2. View all Records
            3. Update Donation record
            4. Delete Donation record
            5. Exit
