1. PROBLEM STATEMENT
When donations are collected during events or activities, the details are usually written somewhere or remembered. This makes it easy to lose information or forget who donated what. It also becomes hard to correct mistakes or check old records.
So, I wanted to make a small system that keeps all donation details in one place and lets the user add, view, update, or delete entries easily.

2. SCOPE OF THE PROJECT
    This project is a simple Python console program that helps manage donation records.
The system stores basic information like donor name, phone number, amount, and date.
The user can add new records, see the list of donations, change any record, or remove it if needed.
The project aims to make donation handling easier for small groups or individuals.

3. TARGET USERS
   Students or coordinators who collect donations for college activities
Small clubs or groups who want a simple record system
Anyone who needs to maintain a list of donation entries without using large software

4. HIGH-LEVEL FEATURES
  Add new donation entry
View all donation records
Edit information of an existing donor
Delete an entry
Simple menu interface so users can easily choose what they want to do
